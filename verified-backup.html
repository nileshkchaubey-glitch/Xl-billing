Privacy and recovery

  • These files may include financial/customer data, full audit history and saved legacy credentials. Keep your Google account and backup folder private. SHA-256 protects file integrity; the file is not encrypted.
  • Keep at least one additional independent copy. Do not delete browser data or old backups before a separate empty-profile restore test.
  • Use one active billing computer/profile. Simultaneous tabs can change records during a backup. If data changes, repeat the backup.
  • This tool does not automatically run while Chrome is closed, and does not promise offline availability if this page has not already been loaded.
  • For unsupported browsers, use Download private backup and move the downloaded file manually to a Google Drive-synced folder; downloaded file persistence is not verified here.
